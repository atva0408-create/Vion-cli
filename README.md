# ViON - CLI

Part of the ViON video surveillance platform ([vionvision.tech](https://vionvision.tech)).

Based on [camera.ui cli](https://github.com/cameraui/cli) by seydx (MIT), used with the author's permission.
npm packages are published under the `@vionvision` scope (`@vionvision/cli`); Python packages and Go module paths keep their upstream names.
To pull upstream changes: `git remote add upstream https://github.com/cameraui/cli.git && git fetch upstream && git merge upstream/main`.
